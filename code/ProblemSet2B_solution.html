Takes a dictionary and prints out the key-value pairs in descending
order by value.

    

    

      
def print_pc_dict(my_dict):

    

  

  

  

    

      

        #
      

      
    

    

      
    result = ''
    for key in sorted(my_dict, key=lambda key: my_dict[key], reverse=True):
        result += key + ":" + str(my_dict[key]) + ", "
    print result[:-2]

    

  

  

  

    

      

        #
      

      
myStream is any music21 Stream object. pc_dict is a dictionary.
Keys in pc_dict correspond to pitch classes (identified by letter name,
such as 'B-' or 'F#') and the associated values correpond to the number
of times the pitch class occurs in the Stream.


This function should return the updated dictionary pc_dict

    

    

      
def pc_freq(myStream, pc_dict):

    

  

  

  

    

      

        #
      

      
    

    

      
    for note in myStream.flat.notes:
        try:
            pc_dict[note.name] += 1
        except KeyError:
            pc_dict[note.name] = 1
    return pc_dict

pc_dict is a dictionary with integer values. Return a dictionary of

dictionary.

    

    

      
def normalize_pc_dict(pc_dict):

    

  

  

  

    

      

        #
      

      
    

    

      
    total = sum(pc_dict.values())

    

  

  

  

    

      

        #
      

      
Note that doing a for ... in ... loop on a dictionary iterates over the keys of the dictionary.

    

    

      
    for key in pc_dict:
        pc_dict[key] = round(float(pc_dict[key]) / float(total), 2)
    return pc_dict
